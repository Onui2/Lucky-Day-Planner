# 토스페이 직접 계약과 리포트 출시

2026-10-16. 토스페이먼츠 PG와 별도 연동입니다.

## 현재 상품 동작

- 기본 4,900원: 공개 무료 체험은 닫혀 있으며 일반 계정은 결제 후 발급합니다.
- 상세 9,900원, 종합 19,900원: 제안 가격. 판매 개방 전 품질·구매 반응 검증이 필요합니다.
- 관리자·최고관리자: 모든 상품 무료. 관리자 발급은 주문과 권한을 먼저 저장한 뒤 한 번만 렌더합니다.
- 가격과 관리자 권한은 서버에서 확인합니다. 이전 클라이언트의 무료 체험 요청은 서버가 거절합니다.
- 생성 실패 시 같은 주문을 마이페이지에서 재생성합니다. 재결제할 필요가 없습니다.
- 기존 발급·구매 PDF는 기존 접근 권한을 유지합니다. 과거 상품 ID로 신규 무료 발급을 우회할 수 없습니다.
- 신규 유료 결제의 웹 열람·PDF 다운로드·재다운로드·재제공 기간은 공급자 승인 시각부터 365일입니다. `purchase_entitlements.expires_at`에 저장하며 재승인·재생성으로 연장하지 않습니다. 기존 무기한 권한과 관리자 무료 발급에는 소급 적용하지 않습니다.

## 2026-10-19 재심사 준비

- 사업자등록증의 상호명·대표자명·사업자등록번호·사업장 주소를 공통 푸터에 표시합니다. 등록증 파일이나 생년월일은 공개하지 않습니다.
- 구매 화면·이용약관·환불정책에 제공 방식과 365일 이용 기간을 표시합니다. 구매 내역에는 개별 만료 시각을 표시합니다.
- 결제 설정이 유효할 때 구매 화면에 실제 사용할 결제수단을 표시합니다.
- 공개 상품 페이지 `/reports`에서 기본 4,900원·상세 9,900원·종합 19,900원의 가격·구성·샘플·제공 기간과 결제수단을 확인할 수 있습니다.
- 무료 분석 결과의 `맞춤 해석 보기`에서도 세 상품 모두 같은 심사용 결제창으로 연결됩니다. 비회원도 확인 가능하며 신년 상품에는 적용하지 않습니다. 실제 판매나 관리자 무료 발급이 가능하면 해당 경로를 우선합니다.
- 계약 전 심사용 결제는 별도 플래그로 켜는 TEST 전용 경로입니다. 토스페이 공식 테스트 키로 실제 토스 결제창을 열고, 인증 후 서버가 승인 결과를 검증합니다. 실거래 결제 설정과는 분리되어 있으며 실제 청구나 유료 리포트 발급으로 안내하지 않습니다.
- 심사용 거래는 암호화된 20분 HttpOnly 쿠키에만 연결합니다. 주문·결제·사주 스냅샷·구매 권한을 DB에 만들지 않으며, 공유 요청 제한만 저장합니다. 따라서 운영 DB의 유료 권한과 테스트 거래가 섞이지 않습니다.
- 재심사에 허용되는 테스트 URL/키 및 구매 경로는 토스페이 담당자의 확인이 필요합니다. 공식 테스트 지원은 해당 심사의 통과를 보장하지 않습니다.
- 실제 판매 전에는 계약 승인, 실거래 키, 판매 설정, 결제·복구 확인, 환불 후 권한 회수 절차가 필요합니다.

## 설정

서버 비밀 환경변수 `TOSS_PAY_API_KEY`에 승인 후 발급받은 키를 설정합니다. 클라이언트 환경변수(`VITE_*`)에 넣지 않습니다.

```dotenv
APP_URL=https://실제서비스도메인
BASE_PATH=/
TOSS_PAY_API_KEY=상점에서_발급받은_키
REPORT_SALES_ENABLED=false
```

개발/검증 환경에는 `sk_test_*`, 운영에는 `sk_live_*`를 사용합니다. `NODE_ENV=production` 또는 `VERCEL_ENV=production`에서는 테스트 키로 결제할 수 없습니다. 두 공급자 키가 모두 있으면 새 주문은 직접 토스페이를 우선합니다. 기존 주문의 공급자는 저장된 정보로 구분합니다.

테스트 환경에서 `REPORT_SALES_ENABLED=true`로 유료 경로를 검증합니다. 운영 판매는 계약 승인·검증 후 별도로 이 값을 `true`로 바꿉니다. 관리자 발급만 이 값이 `false`여도 작동합니다.

### 계약 전 심사용 결제창

다음 서버 환경변수를 설정하고 재배포합니다. 쿠키 비밀값은 `crypto.randomBytes(32).toString("hex")`로 생성한 독립적인 64자리 16진수입니다. 키와 비밀값은 저장소·클라이언트에 넣지 않습니다.

```dotenv
APP_URL=https://myunghaewon.site
TOSS_PAY_REVIEW_ENABLED=true
TOSS_PAY_REVIEW_API_KEY=공식_또는_발급받은_sk_test_키
TOSS_PAY_REVIEW_COOKIE_SECRET=독립적인_64자리_16진수
REPORT_SALES_ENABLED=false
```

`무료 분석 → 맞춤 해석 보기 → 리포트 선택` 또는 `/reports → 리포트 선택` → 토스페이 선택 → 테스트 결제 → 토스 인증 → `/reports` 승인 결과 순서입니다. 두 진입점은 동일한 결제 UI와 API를 사용합니다. 이 경로는 LIVE 키를 거절하고 `REPORT_PRODUCTS`의 상품별 가격 4,900원·9,900원·19,900원을 서버에서 결정합니다. 클라이언트의 임의 금액·제목은 사용하지 않습니다. 상품 종류도 암호화 쿠키에 기록하며 승인 결과는 이 값을 기준으로 표시합니다. 동일 출처 요청, 브라우저 쿠키, 토스의 주문번호·토큰·금액·통화·TEST 모드·승인 시각을 확인합니다. 일반 유료 결제 경로의 운영 TEST 키 거절 정책은 유지합니다.

계약 승인 후 실제 판매를 열 때에는 `TOSS_PAY_REVIEW_ENABLED=false`로 테스트 안내를 내리고 위의 실거래 설정을 적용합니다. 테스트 결제창 제공만으로 실제 구매 가능 요건 충족이나 재심사 통과를 보장하지 않습니다.

## 승인과 복구

서버가 저장된 상품·금액으로 토스페이 결제창을 생성합니다. `autoExecute=false`이므로 구매자 인증 후 서버가 상태·주문번호·금액·토큰·TEST/LIVE를 대조하고 승인합니다. 복귀 URL의 성공 문구만으로 구매 권한을 주지 않습니다.

승인과 접근권한을 DB에 먼저 저장한 후 PDF를 만듭니다. 통신이 끊겨도 마이페이지의 결제 확인으로 이미 승인된 결제를 조회할 수 있습니다. 인증만 완료하고 승인 전 이탈했다면 재결제 전에 상태를 확인해야 합니다. 결제창이 만료되면 새 주문으로 진행합니다.

환불은 현재 토스페이 파트너스에서 처리합니다. 파트너스에서 처리한 환불의 구매 권한 자동 회수는 아직 없습니다. 판매 개방 전 환불 처리와 서비스 접근 회수 운영 절차를 마련해야 합니다.

## 검증 범위와 남은 실기기 확인

격리된 공급자/DB 대역으로 가격 변조·소유권·중복 승인·PDF 실패 복구·무료 체험 차단을 검증합니다. PDF는 실제 렌더링합니다. 이 검증은 실제 상점 계정의 토스 앱 인증을 대체하지 않습니다.

승인된 테스트 키로 PC/휴대폰 결제창 → 토스 앱 인증 → 승인 → PDF → 마이페이지 재다운로드, 인증 취소, 통신 중단 복구를 확인합니다. 실제 거래를 임의로 생성하지 않습니다.
