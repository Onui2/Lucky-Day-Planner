# 토스페이 직접 계약과 리포트 출시

2026-10-16. 토스페이먼츠 PG와 별도 연동입니다.

## 현재 상품 동작

- 기본 4,900원: 계정당 첫 1회 무료. 첫 발급은 결제 설정 없이도 가능합니다.
- 상세 9,900원, 종합 19,900원: 제안 가격. 판매 개방 전 품질·구매 반응 검증이 필요합니다.
- 관리자·최고관리자: 모든 상품 무료. 관리자 발급은 무료 체험을 소비하지 않습니다.
- 가격·관리자 권한·무료 체험 여부는 서버에서 확인합니다. 동시 요청은 계정별 DB 잠금으로 한 번만 발급합니다.
- 생성 실패 시 같은 주문을 마이페이지에서 재생성합니다. 무료 체험을 다시 쓰거나 재결제할 필요가 없습니다.
- 기존 발급·구매 PDF는 기존 접근 권한을 유지합니다. 과거 상품 ID로 신규 무료 발급을 우회할 수 없습니다.

## 설정

서버 비밀 환경변수 `TOSS_PAY_API_KEY`에 승인 후 발급받은 키를 설정합니다. 클라이언트 환경변수(`VITE_*`)에 넣지 않습니다.

```dotenv
APP_URL=https://실제서비스도메인
BASE_PATH=/
TOSS_PAY_API_KEY=상점에서_발급받은_키
REPORT_SALES_ENABLED=false
```

개발/검증 환경에는 `sk_test_*`, 운영에는 `sk_live_*`를 사용합니다. `NODE_ENV=production` 또는 `VERCEL_ENV=production`에서는 테스트 키로 결제할 수 없습니다. 두 공급자 키가 모두 있으면 새 주문은 직접 토스페이를 우선합니다. 기존 주문의 공급자는 저장된 정보로 구분합니다.

테스트 환경에서 `REPORT_SALES_ENABLED=true`로 유료 경로를 검증합니다. 운영 판매는 계약 승인·검증 후 별도로 이 값을 `true`로 바꿉니다. 기본형 첫 무료와 관리자 발급은 이 값이 `false`여도 작동합니다.

## 승인과 복구

서버가 저장된 상품·금액으로 토스페이 결제창을 생성합니다. `autoExecute=false`이므로 구매자 인증 후 서버가 상태·주문번호·금액·토큰·TEST/LIVE를 대조하고 승인합니다. 복귀 URL의 성공 문구만으로 구매 권한을 주지 않습니다.

승인과 접근권한을 DB에 먼저 저장한 후 PDF를 만듭니다. 통신이 끊겨도 마이페이지의 결제 확인으로 이미 승인된 결제를 조회할 수 있습니다. 인증만 완료하고 승인 전 이탈했다면 재결제 전에 상태를 확인해야 합니다. 결제창이 만료되면 새 주문으로 진행합니다.

환불은 현재 토스페이 파트너스에서 처리합니다. 파트너스에서 처리한 환불의 구매 권한 자동 회수는 아직 없습니다. 판매 개방 전 환불 처리와 서비스 접근 회수 운영 절차를 마련해야 합니다.

## 검증 범위와 남은 실기기 확인

격리된 공급자/DB 대역으로 가격 변조·소유권·중복 승인·PDF 실패 복구·무료 1회 발급을 검증합니다. PDF는 실제 렌더링합니다. 이 검증은 실제 상점 계정의 토스 앱 인증을 대체하지 않습니다.

승인된 테스트 키로 PC/휴대폰 결제창 → 토스 앱 인증 → 승인 → PDF → 마이페이지 재다운로드, 인증 취소, 통신 중단 복구를 확인합니다. 실제 거래를 임의로 생성하지 않습니다.
