# 카카오·Google 로그인 설정

이메일 가입과 기존 회원 로그인을 유지합니다. SNS는 기존 서버 세션을 사용하는 직접 OpenID Connect 방식입니다. Supabase의 별도 로그인 설정은 필요하지 않습니다.

## 배포 환경변수

- `APP_URL`: 최종 운영 주소의 origin(예: `https://example.com`). 하위 경로·쿼리·인증정보 없이 지정합니다. 운영은 HTTPS 필수입니다.
- `SOCIAL_AUTH_COOKIE_SECRET`: 암호학적 난수 32바이트를 hex로 표현한 64자리 값. 서버 인스턴스마다 같은 값을 사용합니다. 키 변경 시 진행 중인 로그인은 만료됩니다.
- `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`
- `KAKAO_OAUTH_CLIENT_ID`, `KAKAO_OAUTH_CLIENT_SECRET`

비밀값은 서버 환경에만 등록합니다. 저장소·채팅·`VITE_` 변수에 넣지 않습니다. 해당 제공자의 설정이 빠지면 로그인 버튼을 노출하지 않습니다. 설정값 존재 검사는 제공자 콘솔 설정이 올바르다는 검증을 대신하지 않습니다.

## 제공자 콘솔

1. Google: 웹 애플리케이션 OAuth 클라이언트를 생성하고 승인된 리디렉션 URI에 `${APP_URL}/api/auth/social/google/callback`을 등록합니다. 동의 화면에 운영 도메인·개인정보처리방침·이용약관을 연결하고 테스트 사용자 제한/게시 상태를 확인합니다.
2. 카카오: 카카오 로그인과 OpenID Connect를 활성화합니다. REST API 키를 client ID로, 활성화한 client secret을 비밀값으로 설정합니다. 리디렉션 URI는 `${APP_URL}/api/auth/social/kakao/callback`입니다.
3. 카카오의 불필요한 닉네임·프로필 사진·이메일 필수 동의항목을 설정하지 않습니다. 구현은 `openid`만 요청하며 회원 식별자만 저장합니다. Google은 `openid email`을 요청하여 식별자와 검증된 이메일만 저장합니다.

Google 공식 [OpenID Connect 안내](https://developers.google.com/identity/openid-connect/openid-connect), 카카오 공식 [로그인 REST API/OIDC 안내](https://developers.kakao.com/docs/ko/kakaologin/rest-api)를 기준으로 구현했습니다.

## 가입과 개인정보

- 신규 이메일 회원: 약관 동의와 개인정보 처리 안내 확인을 모두 명시해야 가입됩니다. 이름은 수집하지 않습니다.
- 신규 SNS 회원: 제공자 인증 → 가입 안내 화면 → 필수 확인 → 계정·확인 기록을 같은 DB 트랜잭션으로 저장 → 로그인 순서입니다. 안내 확인 전에는 서비스 계정을 생성하지 않습니다.
- `registration_consents`에 사용자, 문안 버전, 가입 방식, 약관 동의 여부, 개인정보 처리 안내 확인 여부와 DB 서버 시간을 기록합니다. 개인정보의 계약 이행 목적 처리 안내 확인을 별도 선택 동의나 마케팅 동의로 기록하지 않습니다. 탈퇴 시 함께 삭제합니다.
- 테이블은 최초 가입 시 별도 추가 마이그레이션으로 생성합니다. RLS를 적용하고 PUBLIC/anon/authenticated의 직접 권한을 회수합니다. DDL 또는 증빙 기록 실패 시 가입을 실패 처리합니다.
- 기존 회원에게 재동의를 요구하지 않습니다. 동의 기록 없는 신규 generic OIDC/Supabase 자동 가입은 차단합니다. 이 경우 사이트의 이메일/카카오/Google 가입 화면에서 진행해야 합니다.
- 같은 이메일의 기존 계정을 자동 연결하지 않습니다. 충돌 시 기존 로그인 방법을 사용합니다. 카카오와 Google은 서로 다른 식별자를 가진 별도 계정으로 취급됩니다. 계정 통합 기능은 포함하지 않습니다.

## 보안과 운영 검증

OAuth state·nonce·S256 PKCE, ID 토큰 서명/issuer/audience/expiry 검증, 고정 callback origin, 시작·가입 완료 요청의 Origin 검증을 사용합니다. 로그인 진행 정보와 가입 전 식별정보는 AES-256-GCM 암호화 HttpOnly/SameSite=Lax 쿠키에 10분간 보관합니다. 제공자 access/refresh token은 서비스 세션에 저장하지 않습니다.

설정 후 실제 브라우저에서 각 제공자별 신규 가입, 기존 회원 로그인, 인증 취소, 동일 이메일 충돌, 동의 미선택 차단, 모바일 복귀를 확인해야 합니다. 현재 자동 검사는 격리된 DB/제공자 모형에서 수행하며 실제 콘솔 키·계정 인증을 대신하지 않습니다.

회원가입 연령 및 만 14세 미만 법정대리인 확인 정책은 별도 확정이 필요합니다. 현재 연령 제한·보호자 동의 완료를 구현했다고 표시하지 않습니다.

## 공개 운영 정보 확인

- 운영 상호: **명해원**, 개인정보 보호 담당자: **이현우**.
- 전용 문의 이메일은 아직 미정입니다. 실제 수신 가능한 주소를 만든 뒤 개인정보처리방침에 추가합니다. 현재 페이지는 기존 문의하기 경로를 안내합니다.
- 실제 이용 중인 인증·호스팅·DB·AI·결제 처리업체, 국외 이전 여부와 국가·항목·기간, 법정 보관기간을 운영 설정과 대조해 보완해야 합니다. 현재 문안을 개인정보 관련 법적 요건 전체가 검증된 상태로 취급하지 않습니다.
