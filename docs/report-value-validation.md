# 리포트 구매 가치 검증

2026-10-16. 사용자에게 들은 수요는 이직·돈·연애 등 특정 고민 풀이입니다. 아직 실제 유료 구매 실적은 없습니다. 아래 가격은 지불 의향이 검증된 가격이 아닙니다.

## 이번 개선

상품 분량보다 고민 선택을 앞에 둡니다. 각 보고서는 개인 사주 해석 근거, 현실에서 대조할 조건, 다음 행동 순으로 시작합니다. 공개 무료 PDF 체험은 닫혀 있으며 기본형은 4,900원입니다. 상세형은 추가 분야의 해설, 종합형은 과거 회고와 미래 연도별 흐름을 제공합니다.

계산 원리는 무료 웹 분석과 같습니다. 높은 가격이 더 높은 예측 정확도를 뜻하지 않습니다. 실제 사건·수익·타인의 마음을 알아낸다고 약속하지 않습니다. PDF는 계산 결과를 주제별로 정리한 보고서이며, 개별 상담사가 작성하거나 검수한 보고서로 표시하지 않습니다.

실제 샘플은 `/report-samples/saju-basic.pdf`, `saju-detail.pdf`, `saju-full.pdf`입니다. 모두 가상 인물의 같은 입력을 사용합니다. 페이지 수 자체는 구매 가치의 증거로 사용하지 않습니다.

## 비공개 사용자 검증에서 확인할 것

먼저 해당 고민이 있는 이용자 5명 정도에게 운영자가 기본 보고서를 제공하고, 설명을 대신해주지 않은 상태에서 읽도록 합니다. 공개 계정의 자동 무료 발급은 사용하지 않습니다. 이는 초기 문제를 찾기 위한 소규모 관찰이지 시장 지불 의향의 통계적 검증이 아닙니다.

1. 어떤 고민으로 들어왔는지 이용자 자신의 문장으로 듣습니다.
2. 읽고 나서 실제로 도움이 된 문장과 일반적인 이야기처럼 느껴진 문장을 각각 짚도록 합니다.
3. 상세형의 추가 내용을 먼저 보여주고, 9,900원을 낼 이유 또는 안 낼 이유를 듣습니다. 호의적인 답변을 결제 수요로 계산하지 않습니다.
4. 실제 판매 개방 후 유료 구매 계정 수, 제공 성공 수, 환불·불만 내용을 함께 봅니다. 자동 발급 성공만으로 PDF를 읽었다고 가정하지 않습니다.
5. 비용을 지불한 이유가 특정 고민에 몰리면 해당 보고서를 먼저 개선합니다. 종합형을 기본 선택하거나 공포·할인 압박으로 구매를 유도하지 않습니다.

기존 DB의 `orders.metadata.freeTrial=true`는 종료 전 무료 체험 발급 기록입니다. 기존 발급 리포트의 접근권은 유지합니다. `status=paid AND amount>0`이 유료 주문입니다. 관리자·개발 시뮬레이션·TEST 결제는 전환 집계에서 제외해야 합니다. 개인의 생년월일·고민 내용을 외부 분석 서비스로 전송하지 않습니다.
